# RcHarness Logo

图形把遥控器与鼠标指针组合，表达“用遥控器操作 Mac”。斜向遥控器保留方向环和三个按键，指针以薄荷绿色强调桌面输入。应用图标使用蓝色圆角底；独立标志使用单色透明底。

## 文件

- `rcharness-icon.svg`：1024 × 1024 可编辑应用图标源稿，画布四周透明。
- `rcharness-icon.png`：1024 × 1024 PNG 应用图标。
- `RcHarness.icns`：macOS 图标，包含 16–1024 px 各档资源。
- `rcharness-mark.svg`：可编辑单色标志，负形区域透明。
- `rcharness-mark.png`：512 × 512 透明 PNG 单色标志。
- `preview.png`：包含主图标、单色版本和小尺寸效果的设计预览。

## 色彩与使用

- 蓝色：`#479BFF` → `#2875ED` → `#244DCC`。
- 薄荷绿：`#97F4DF`。
- 单色墨蓝：`#172B4D`。在深色背景上可统一替换为白色。
- 保留应用图标自带的外侧透明留白，不再次添加圆角蒙版。
- 单色标志保留四周至少一个方向环半径的留白。
- 16–24 px 菜单栏场景建议另画简化版，去掉三个小按键后再接入；本稿未替换当前菜单栏状态文字。

## 制作

本方案直接绘制 SVG，未调用图像生成模型。SVG 使用 macOS Quick Look 渲染，ImageMagick 恢复透明通道并缩放，ICNS 使用 macOS 的 `sips` 与 `iconutil` 打包。仅交付设计资源，尚未接入应用构建。
